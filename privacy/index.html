참새 개인정보처리방침

시행일: 2026년 10월 18일 · 적용 앱: 참새 (Android, 패키지명 com.abc100.chamsae)

한눈에 보기
  • 참새는 개인정보를 수집하지 않습니다. 회원가입, 로그인, 광고, 분석 도구가 없습니다.
  • 참새에는 인터넷 권한이 없습니다. 그래서 어떤 정보도 기기 밖으로 보낼 수 없습니다.
  • 접근성 API는 숏폼 화면을 알아보고 빠져나오게 하는 데에만 쓰며, 화면 내용을 저장하지 않습니다.

1. 수집하는 개인정보

참새는 이름, 연락처, 계정, 위치, 기기 식별자, 광고 식별자 등 어떠한 개인정보도 수집하지 않습니다. 운영자는 이용자의 정보를 받을 수 있는 서버를 운영하지 않으며, 앱에는 네트워크 통신을 위한 인터넷 권한 자체가 없습니다.

2. 접근성 API(AccessibilityService) 사용

참새는 Android 접근성 API를 사용합니다. 장애인 보조 기능이 아니라, 이용자가 직접 켠 경우에만 아래 목적에 한해 동작합니다.

확인하는 정보유튜브(YouTube), 인스타그램(Instagram), 틱톡(TikTok), 네이버 웹툰 앱이 화면에 떠 있을 때, 지금 화면이 쇼츠·릴스·피드인지(틱톡·웹툰은 앱이 앞에 있는지) 알아보기 위한 화면 구성 요소의 이름(ID)과 선택 상태. 잠깐 보기를 쓰는 동안에는 시간 계산을 위해 지금 앞에 있는 앱이 무엇인지(앱 패키지명).
하는 동작막기로 설정한 화면이 뜨면 정해진 규칙에 따라 뒤로가기, 홈으로 가기, 인스타그램 메시지 탭 누르기 중 하나를 대신합니다. 그 밖의 동작은 하지 않으며, 앱이 스스로 판단해 다른 행동을 하지 않습니다.
읽지 않는 정보메시지 내용, 게시물·댓글 텍스트, 사진·영상, 입력하는 글자, 비밀번호 등은 읽거나 저장하지 않습니다.
저장·전송확인한 화면 정보는 그 순간 기기 안에서 판단하는 데에만 쓰고 저장하지 않습니다. 인터넷 권한이 없어 외부로 전송할 수 없습니다.

접근성 권한은 앱 안의 안내 화면에서 동의한 경우에만 설정할 수 있고, 기기 설정 > 접근성에서 언제든 끌 수 있습니다.

3. 기기 안에만 저장하는 정보

앱 기능을 위해 아래 정보를 이용자의 기기 안 앱 전용 저장공간에만 저장합니다. 운영자를 포함해 누구에게도 전달되지 않습니다.

  • 막을 화면 설정, 참새 애니메이션 설정, 접근성 안내 동의 여부
  • 날짜별 막은 횟수(최근 14일)와 참새가 켜져 있던 날 기록, 잠깐 보기 사용 횟수와 남은 시간
  • 이용자가 직접 입력한 "지금 해야 할 일" 목록
  • 친구 잠금을 켠 경우: 친구가 정한 비밀번호를 무작위 값(솔트)과 섞어 SHA-256으로 변환한 값(해시), 비상 해제를 시작한 시각, 틀린 횟수. 비밀번호 숫자 자체는 저장하지 않습니다.

"기록 카드 공유"는 이용자가 공유 버튼을 누를 때에만 이번 주 막은 횟수 합계, 연속 일수, 요일별 지킨 날을 그린 이미지를 앱 임시 폴더(캐시)에 만들고, 이용자가 고른 앱(메신저 등)에 넘겨 줍니다. 이미지에는 어떤 앱이나 영상을 막았는지는 들어가지 않으며, 참새가 직접 어디로 보내지는 않습니다. 이용자가 고른 앱으로 넘긴 뒤의 처리는 그 앱의 방침을 따릅니다.

이 정보는 Android 자동 백업과 기기 간 데이터 이전에서도 제외되도록 설정되어 있어 클라우드로 백업되지 않습니다. 앱을 삭제하거나 기기 설정에서 앱 데이터를 삭제하면 즉시 지워집니다.

4. 앱이 요청하는 권한

접근성 서비스숏폼 화면 감지와 빠져나오기 (2항 참고)
알림잠깐 보기 남은 시간 표시, 참새가 꺼졌을 때 알림
부팅 완료 수신기기를 다시 켠 뒤에도 "참새가 꺼졌는지" 확인하는 작업을 유지하기 위함

참새는 인터넷, 위치, 연락처, 카메라, 마이크, 저장소 권한을 요청하지 않습니다. 일부 기기(삼성 등)에서 차단이 늦어지지 않도록 배터리 최적화에서 빼 달라고 안내할 수 있지만, 이를 위한 별도 권한은 요청하지 않고 이용자가 직접 기기 설정 화면에서 바꾸도록 설정 화면만 열어 드립니다.

5. 제3자 제공 및 처리 위탁

수집하는 개인정보가 없으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다. 광고 SDK, 분석 SDK, 오류 수집 SDK 등 외부 업체의 코드를 포함하지 않습니다.

6. 보유 기간과 파기

운영자가 보유하는 개인정보는 없습니다. 기기 안에 저장된 정보(3항)는 이용자가 앱을 삭제하거나 앱 데이터를 지우면 즉시 파기됩니다.

Chamsae Privacy Policy (English summary)

Effective October 18, 2026 · App: Chamsae (Android, com.abc100.chamsae)

  • No data collection. Chamsae does not collect, store on any server, share, or sell any personal or sensitive data. There are no accounts, ads, analytics, or crash-reporting SDKs.
  • No internet permission. The app does not declare the INTERNET permission, so it cannot transmit any data off the device.
  • Accessibility API. Chamsae uses the AccessibilityService API (it is not an accessibility tool for people with disabilities). Only while YouTube, Instagram, TikTok, or Naver Webtoon is on screen, it checks view IDs and selection state to detect Shorts, Reels, or the home feed, and then performs one fixed action: Back, Home, or tapping Instagram's Messages tab. During a timed break it checks which app is in the foreground. It does not read message contents, post text, media, or typed input, and it does not store what it sees.
  • On-device data only. Settings, daily block counts (last 14 days), break usage, the user's to-do list, and, if Friend Lock is used, a salted SHA-256 hash of the friend's PIN (never the PIN itself) are stored in app-private storage on the device, excluded from Android cloud backup and device transfer, and deleted when the app or its data is removed.
  • Share card. Only when the user taps Share, the app draws an image with aggregated weekly numbers (total blocks, streak, kept days; no app or video details) into its cache and hands it to the app the user picks via the Android share sheet. Chamsae itself sends nothing.
  • Permissions: Accessibility service, notifications, and boot completed (to keep the status check). The app does not request REQUEST_IGNORE_BATTERY_OPTIMIZATIONS; it only opens the system app-info screen so the user can change battery settings themselves. No location, contacts, camera, microphone, or storage access.
